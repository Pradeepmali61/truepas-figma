PRD v2.0 Key Requirements

Mandatory face enrollment gate (no skip)
Biometric consent before face capture
Document types: Passport, DL, ID Card
Selfie + document portrait matching
Profile mismatch with 15-min TTL session
Family age rules: 0-4, 5-17, 18+
Guardianship consent for minors
Age-18 transition notification
Data deletion: PostgreSQL + S3 + ROC
PIN required for face updates
ROC retry on failure (no false success)
Biometric consent withdrawal

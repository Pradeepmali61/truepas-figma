# Document Logos

Place the real document logo images here with the following filenames:

- `aadhaar.png` — Aadhaar logo
- `dl.png` — Driving License / RTO emblem
- `pan.png` — PAN / Income Tax Department logo
- `passport.png` — Passport / external affairs emblem

Once saved, the `03-documents.html` mockup will display these images in the Issued Documents list.
